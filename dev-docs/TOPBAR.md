# 顶栏与导航条目

顶栏由一组可配置条目组成：内置页面和插件动作都可以出现在顶栏里。
TUI 使用窗口顶部的一行标签；GTK 使用左侧导航栏（用户要求沿用侧栏的
交互），两者共享同一份配置。

## 条目与默认值

内置页面：

- `page:home`、`page:news`、`page:contact`、`page:platform`、
  `page:search`、`page:forum`、`page:me`；
- GTK 还可能有 `page:plugins`（可选插件总览页）。

插件动作：

- `plugin:<plugin-id>:<action-id>`，由当前插件暴露且当前令牌 scopes
  允许的动作自动生成；
- 默认 `visible = false`、`collapsed = true`，避免插件一安装就占满顶栏。

内置页面默认可见且不折叠。

## 配置

```toml
[topbar]

[[topbar.items]]
id = "page:home"
visible = true
collapsed = false

[[topbar.items]]
id = "plugin:news-admin:save-news"
visible = true
collapsed = false
```

- **顺序**：数组顺序就是顶栏顺序；新发现但配置里没有的条目追加在末尾。
- **可见性**：`visible = false` 的条目不出现在顶栏，也不在“已折叠”里。
- **折叠**：`collapsed = true` 且可见的条目收进最后的“已折叠”项。
- 配置里已被删除的插件/页面 id 会被忽略；下一次保存时自动清理。

## TUI

- `←` / `→` 选中顶栏条目（TUI 顶栏没有独立的焦点框，选中项反色显示）；
- `Enter` / `Space` 打开选中项；页面会切换，插件动作会打开动作表单；
- 最后一项是“已折叠 ▾”，`Enter` 在顶栏下打开一行可左右滑动的折叠条目，
  当前项尽量居中；`←` / `→` 或 `h` / `l` 滑动，`Enter` 选择，`Esc` 关闭；
- 选择折叠条目后，最后一项的文案变为该条目并保留小三角；
- 设置 → 顶栏元素：`Space` 显示/隐藏，`c` 折叠，`J` / `K` 下移/上移。

## GTK

- 侧栏按配置显示未折叠条目，末尾是“已折叠 ▾”；
- 点击“已折叠”会把主栏向左滑动隐藏，显示折叠条目列表，顶部有“返回”；
- 点击折叠条目会执行它并滑回主栏，同时“已折叠”行改为该条目名称；
- 设置 → 顶栏 → 顶栏元素：每项有“显示”“折叠”开关和上下移动按钮。

## 插件接口

插件不需要新增 ABI 调用：插件通过现有的 `actions_json` / `run_json`
暴露动作，宿主自动把允许的动作加进顶栏候选。动作有字段时，从顶栏打开
会走现有的表单/对话框；没有字段时同样可以打开表单后确认执行。

如果以后需要插件自带图标或自定义顶栏标签，可以再给动作描述增加可选字段，
当前实现直接使用 `title`。
